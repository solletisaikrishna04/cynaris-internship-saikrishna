# W5D5 – AI-Powered EDA on Indian Business Dataset

## Project Overview
This project performs Exploratory Data Analysis (EDA) on an Indian Business Dataset using Python, Pandas, NumPy, Matplotlib and PandasAI.

## Objectives
- Understand Indian business data.
- Identify and handle missing values.
- Remove duplicate records.
- Analyze business revenue.
- Compare state-wise and city-wise performance.
- Generate AI-powered business insights.
- Create data visualizations.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- PandasAI
- Ollama
- Qwen 2.5 3B
- Jupyter Notebook

## Data Cleaning
- Identified missing email values.
- Replaced missing emails with "Not Available".
- Checked and removed duplicate records.

## AI-Powered Analysis
Used PandasAI with a locally running Ollama model to ask natural-language questions about business revenue, state performance and city distribution.

- Business Count by State
