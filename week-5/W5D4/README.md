# W5D4 – Polars: High-Performance DataFrame Operations

## Project Overview
This project demonstrates high-performance data analysis using Pandas, DuckDB and Polars.

## Dataset
- Indian Business Dataset: Business-level exploratory data analysis.
- Indian Retail Sales Dataset: 100,000-row performance benchmarking.

## Technologies Used
- Python
- Pandas
- DuckDB
- Polars
- Matplotlib
- Jupyter Notebook

## Tasks Completed
1. Loaded and analysed the Indian Business Dataset.
2. Performed five analytical SQL queries using DuckDB.
3. Performed equivalent DataFrame operations using Polars.
4. Benchmarked Pandas, DuckDB and Polars.
5. Created a performance comparison chart.
6. Documented the findings.

## Key Concepts
- DataFrame operations
- Columnar processing
- SQL analytics
- GroupBy and aggregation
- Lazy execution
- Performance benchmarking

## Conclusion
Pandas, DuckDB and Polars provide different approaches to data analytics. Pandas is useful for general data manipulation, DuckDB for analytical SQL queries, and Polars for efficient DataFrame processing.

Execution-time results are documented in the project notebook.
